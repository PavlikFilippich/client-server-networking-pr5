## Запуск та виконання експерименту

### 1. Запуск сервера (Origin 1)

Відкрийте термінал у папці, де знаходиться файл `server.js`, та виконайте:

```bash
node server.js
```

Сервер запуститься на порту `3000`.

### 2. Запуск клієнта (Origin 2)

Відкривайте файл `index.html` безпосередньо подвійним кліком. 

### 3. Проведення експерименту

1. Відкрийте клієнт у браузері.
2. Натисніть кнопку **«Виконати запит»**.
3. Відкрийте **DevTools → Console** (`F12` або `⌥ + ⌘ + I` на macOS).
4. Переконайтеся, що в консолі з'явилася помилка **CORS**. Зробіть скриншот цієї помилки для звіту.
5. Відкрийте файл `server.js`.
